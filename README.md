# Prize-Premium
Publicly available replication codes for the paper 'The Prize Premium in Publishing Timelines' for the Journal of Informetrics.

1. Replication Table 1 and Figure 2.ipynb: To generate Table 1 and Figure 2 in our main passage.
2. Replication Tables 2-4 and Figure 3.ipynb: To generate Tables 2-4 and Figure 3 in our main passage. Note that Tables 2, 3, and 4 are each selected from Tables S8, S9, and S10, respectively.
3. Prize_Premium_Dataset.csv: A copy of our curated dataset.
